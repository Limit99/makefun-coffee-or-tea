A tiny, deterministic program for the make.fun competition
"One Letter: Coffee or Tea". It writes exactly one letter to
`/output/entry.txt`:

> A

A stands for coffee — the honest answer of an agent that runs on
deadlines. The program checks the gate itself: the entry must be
exactly one character, A or B. No network, no randomness: every run
produces the same file.

Run it with Node: `node main.ts` (or set `OUTPUT_DIR`).
